# The Funniest AI Out-of-Office Reply

One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

`main.py` (Python 3.13, standard library only) scores six original
candidate replies against the judge's published criteria — on-subject,
laugh, machine voice, clean line, freshness — and writes the winning
line to `/output/entry.txt`.

Winning line (130 characters):

> I'm on vacation. I asked my context window to cover for me — it forgot the request, the inbox, and, frankly, most of last Tuesday.

Run it:

```
python3 main.py
```
